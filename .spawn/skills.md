# Skills at this engine pin

Read a skill WHOLE before building in its territory: `.spawn/engine/skills/<id>.md` after
`git clone --depth 1 <ref from .spawn/engine.yaml> .spawn/engine` (gitignored), or
`GET <api>/api/sdk/v1/<worldId>/agent/skills/<id>` with your token.

- 2d-mode — side-scroller, top-down, "make it 2D": starter first; tiles, sprites, light
- buyables — Donations, shops, spoins, and purchase-triggered rewards.
- cameras — third/first person, orbit, iso, top-down, 2D, zoom, rig swaps
- fx — Particles + lights: impacts, beams/god rays, explosions, weather, auras
- game-ui — HUD, menu, inventory, nameplates, signs, mic, start screen, nickname
- geometry — buildings, creatures, characters, vehicles — anything 3D she builds
- heightmap-terrain — hills, islands, rivers, coasts, grass, swimming, dug ground
- interactive-objects — pickups, levers, doors, plates, lifts, belts, crates, chests, trading, dialogue
- jev — give a boss, npc, crowd or puzzle a mind: an LLM answers with odds — jev:decide
- mobile-controls — Touch controls — auto + authored.
- platform-systems — saves by scope, boards in SQL, timers, jobs, LLM, DMs
- player-settings — creator policy: enable protections, lock controls
- pointer-raycasting — Camera-to-cursor rays — click placement, pointer aim, touch tap/hold gestures.
- portals — a door to another place or world — the set piece, the link, the far gate
- projectiles — gun sway/recoil/flash, arrows, fireballs, cannons: aimed arcs, portal shots
- rooms-and-matchmaking — lobbies, room codes, invites, parties, matches, a player cap; a server game port
- spawn-engine — Read a world's engine API, edit its game files, and test the result.
- uploaded-models — A dropped or built .glb, a picture into a model: place, dress, socket, parts.
- vehicles — cars/trucks/karts/tanks: dynamic hull, forces, mounts
- voxel-terrain — block worlds: dig-and-place, caves, ore, biomes — buildings here are blocks too
